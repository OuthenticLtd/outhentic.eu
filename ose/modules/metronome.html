Try it · The real metronome

Tap START. Hear the click. See the polygon morph.

30–300 BPM, 1–16 beats per bar, /4 /8 /16 note values. Tap any beat in the strip to cycle normal → accent → muted → normal. The polygon morphs to match the beat count: triangle (3), square (4), pentagon (5), hexagon (6) — all the way through hexadecagon (16). The click is generated with the same 1500/1000 Hz sine + 50 ms linear decay envelope the app uses.
